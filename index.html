documindLive

DocuMind

Ask RBI regulations a question. Get an answer that cites the paragraph.

A retrieval-augmented question-answering system over 42 Reserve Bank of India Directions. Every answer cites the document, chapter, paragraph and page it comes from, and when the documents don't cover a question, DocuMind says so instead of guessing.

  • Hybrid search (BM25 + bge embeddings in Qdrant), LLM query rewriting and a cross-encoder reranker, each chosen by experiment
  • Measured on 128 reviewed questions with an LLM judge (audited: 30/30 faithfulness agreement). A paraphrased test set showed keyword recall@5 falling from 0.93 to 0.61 with everyday wording, and query rewriting cut false refusals from 23.5% to 13.7%
  • Built to run as a service: answer cache, rate limits, request logs, FastAPI, GitHub Actions CI with 67 tests

finsight-aiLive

FinSight AI

See where your money goes.

Upload a bank statement and FinSight cleans it, sorts every transaction into a category, flags unusual spending and finds your subscriptions. An AI assistant answers questions like "How much did I spend on food last month?" using only numbers the app has already calculated.

  • Rules sort most transactions instantly; a TF-IDF + Naive Bayes model trained on your own history only steps in when it's more confident
  • Anomaly detection, recurring-payment detection and a spending forecast that says so when there isn't enough history
  • Secure multi-user accounts: JWT auth, bcrypt, rate limiting and every query scoped to the signed-in user

Gym CRM

One app to run a gym, with AI training plans built in.

A multi-gym SaaS app for owners, managers, trainers and front-desk staff. It handles members and custom plans, renewal reminders, weekly check-ups with progress photos, leads, payments and analytics. Trainers generate a 4-week workout and diet plan with Claude, review it, and share it with the member through a private link.

ChurnRadar

Know which customers are about to leave, and why.

Predicts whether a telecom customer will churn, explains each prediction with SHAP, and suggests retention actions from a playbook. Trained on the IBM Telco dataset (7,043 customers).

  • Compared five models; XGBoost tuned with Optuna won. The decision threshold was tuned on cross-validated training data, never the test set
  • Streamlit dashboard: a what-if customer lab, batch scoring from PDF or CSV, revenue at risk and model insights
  • FastAPI service for single and batch predictions, with a pytest suite and Docker image
